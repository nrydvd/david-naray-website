# David Naray weboldal

Statikus HTML, CSS és JavaScript weboldal GitHub Pages-hez.

## Feltöltés GitHubra

A repository gyökerébe az alábbi elemek kerüljenek:

- `index.html` - főoldal
- `style.css` és `script.js` - főoldal stílusai és működése
- `david.png` és `file.png` - képek
- `adatkezelesi-tajekoztato/` - adatkezelési tájékoztató
- `pages/landing-pages/` - különálló landing oldal

A `private.txt` fájlt ne töltsd fel GitHubra. Titkos adatokat tartalmaz, és a `.gitignore` már kizárja.

GitHubon a Pages beállításnál válaszd a repository `main` ágát és a `/ (root)` mappát.
